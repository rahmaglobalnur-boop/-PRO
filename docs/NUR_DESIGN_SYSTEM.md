## 🎨 Цветовая система (CSS Tokens)

| Токен | HEX | Применение |
|---|---|---|
| `--black` | `#000000` | Основной фон (тёмные секции) |
| `--white` | `#FFFFFF` | Светлые секции (История, Партнёры, Контакт) |
| `--gold` | `#C9A84C` | Только логотип NUR· и интро |
| `--gold2` | `#E8C97A` | Арабский текст в интро |
| `--teal` | `#00B4A6` | SARDOR AI — единственный акцент |
| `--g1` | `#0D0D0D` | Фон тёмных вторичных секций |
| `--g2` | `#111111` | Разделители, бордеры |
| `--g4` | `#333333` | Плейсхолдеры, копирайт |
| `--g5` | `#555555` | Вторичный текст (тёмный фон) |
| `--g6` | `#888888` | Описания, подписи |

**Правило монохрома:** золото только в логотипе и цитате хадиса. Везде остальном — чёрный/белый/серый. Apple-принцип: один акцент, тысяча оттенков серого.

## 🃏 Компоненты — правила

**Карточки (тёмный фон)**
- Бордер: `1px solid #111`
- Hover: `background rgba(255,255,255,.015)` — почти незаметно
- `::before` accent line: `rgba(255,255,255,.08)` — не золото
- Radius: **0** — острые Apple углы

**Карточки (белый фон)**
- Бордер: `1px solid #EBEBEB`
- Hover: `background #FAFAFA`
- Radius: **0**

**Кнопки**
- Primary (тёмный фон): `background #FFF; color #000` — инвертировано
- Primary (светлый фон): `background #000; color #FFF`
- Border CTA: `border 1px solid rgba(255,255,255,.2)` → hover: `#FFF / #000`
- Нет золотых кнопок нигде, кроме submit формы

**Навигация**
- `backdrop-filter: blur(20px)`, `background rgba(0,0,0,.96)`
- Border bottom: `1px solid rgba(255,255,255,.07)`
- Logo: `17px / 900 / .06em`
- Links: `rgba(255,255,255,.5)` → hover `#FFF`

**Форма (белый фон)**
- Input border: `1px solid #E0E0E0` → focus: `#000`
- Background input: `#FFFFFF`
- Submit: `background #000; color #FFF`
- No gold anywhere in form

## 🎬 Влияния и референсы

**Alexander Laguta — ключевые принципы**
- Extreme contrast — рядом самый большой и самый маленький элемент
- Bold + Outline — заполненный и контурный текст в одном заголовке
- Swiss grid — 4-column, жёсткая сетка, никаких хаотичных отступов
- Minimal color — 1 акцент максимум, остальное ч/б
- Type as image — типографика = главный визуальный элемент
- Editorial tension — напряжение между крупным и мелким

**Apple Design Language**
- Белые секции как "воздух" между тёмными
- `-webkit-font-smoothing: antialiased` всегда
- Анимации быстрые и короткие (≤500ms)
- Hover-эффекты едва заметны — не кричат
- Один главный CTA, остальное — ghost/border
- Скроллбар: `2px / #222` — ультратонкий

## 🤖 Sardor AI — особый стиль

- Цвет акцента: `#00B4A6` (teal) — единственный нечёрно-белый цвет в услугах
- Пульсирующая точка: `animation pulse 2s ease infinite`

## 🧠 Когнитивные UX-паттерны — слой поверх Design System

> Вдохновлено библиотекой UX Core (Wolf Alexanyan, keepsimple.io/ru/uxcore), адаптировано под три отряда NUR.

**Этическая рамка (обязательна):** продукты NUR — халяль-бренды. Паттерны используются только для снижения когнитивной нагрузки и повышения ясности, никогда для манипуляции (без ложного дефицита, fake-таймеров, скрытых условий).

| Паттерн | Механизм | Применение в NUR OS | Где |
|---|---|---|---|
| Von Restorff (эффект изоляции) | Мозг запоминает выбивающееся из ряда | Единственный teal-акцент на монохромном фоне | Sardor AI карточка |
| Hick's Law | Время решения растёт с числом вариантов | 1 primary CTA на экран, остальное — ghost/border | Контакт-форма, Услуги |
| Aesthetic-Usability Effect | Красивое = удобное и заслуживающее доверия | Apple-монохром + Лагута-типографика как сигнал доверия B2G/B2B | Вся система |
| Cognitive Fluency | Легко читаемое = более правдивое | Space Grotesk, много воздуха, короткие подписи | Типографика |
| Chunking | Мозг усваивает блоками по 3–5 единиц | Секции строго по 1 идее, ритм светлое/тёмное | Структура страницы |
| Peak-End Rule | Опыт запоминается по пику и завершению | Финальный экран (submit) — самый чистый на сайте | Контакт + Форма |
| Authority Bias | Доверие к авторитетному источнику | Хадисы только с иснадом и указанием учёного | Интро, Стандарты |
| Halo Effect | Одно позитивное качество красит всё | "Партнёры" на белом сразу после "Истории" | Партнёры, История |
| Framing Effect | Подача меняет восприятие факта | Продукты подаются через пользу, не через страх | Продуктовые описания |
| Zeigarnik Effect | Незавершённое держит в напряжении | Прогресс-индикаторы, counter stats | Формы, Статистика |
| Consistency Bias | Единый паттерн = меньше недоверия | Один дизайн-язык во всех трёх отрядах | Кросс-брендинг |

**Чек-лист перед релизом экрана:**
- [ ] Один primary CTA на экране? (Hick's Law)
- [ ] Нет ложного давления/дефицита? (этическая рамка)
- [ ] Финальный шаг — самый чистый экран? (Peak-End)
- [ ] Акцент использован не более чем в одном месте? (Von Restorff)
- [ ] Решение можно обосновать паттерном, а не вкусом?
