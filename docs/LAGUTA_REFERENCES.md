# Референсы Лагуты — что взято из A.LAGUTA

Картинки лежат в приватном репозитории `rahmaglobalnur-boop/A.LAGUTA` (36 PNG, ~150 МБ).
Сюда не копировались из-за веса. Ниже то, что из них вынесено для работы.

## GRID.png — тёмный editorial-шаблон
- Фон почти чёрный (`#111`), текст белый, подписи серые мелким кеглем.
- Заголовки — широкий декоративный display-шрифт, капс, огромный кегль. Рядом — body 12–13px.
  Это и есть «экстремальный контраст масштаба».
- Двухтоновый заголовок: первая строка серая, вторая белая (WHAT / WE DO).
- Заголовок наезжает на фото: типографика поверх изображения, а не рядом.
- Фото разных размеров, ступенчатая раскладка, но все левые края привязаны к сетке.
- Блок цифр: 36 / 225 / 104 / 15 крупно, под каждой короткая подпись в 2–3 строки.
- Одна кнопка на экран, ghost с тонкой обводкой (Learn more).

## OPERA AUSTRALIA.png — лендинг о здании, Лагута-разбор
- Чёрный фон, гротеск-капс в hero, рядом курсив-антиква (Playfair-подобный) для «атмосферных» заголовков.
  Смешение гротеска и курсивной антиквы — главный приём страницы.
- Крупные цифры с единицами (22 000 м², 185×120 м) против мелкого описания.
- Красные рамки на скриншоте — разметка секций, показывает ритм: одна идея на секцию.
- Галерея в конце — мозаика фото с разной высотой, без скруглений.
- Footer: две колонки (услуги / соцсети), мелкий текст.

## Правила, которые из этого следуют
1. Swiss grid, 4 колонки, всё по левому краю.
2. Самый большой элемент стоит рядом с самым маленьким.
3. Типографика — главный визуальный элемент. Bold + outline, или гротеск + курсив в одном заголовке.
4. Максимум один цветовой акцент.
5. Напряжение между крупным и мелким, воздух между секциями.
6. Manhaj-фильтр: в референсах есть лица людей — в NUR/Rahma проектах их заменять
   геометрией, архитектурой, предметкой без людей.
