## 🎨 Цветовые токены (не менять значения)

| Токен | HEX | Применение |
|---|---|---|
| `--black` | `#000000` | Основной фон (тёмные секции) |
| `--white` | `#FFFFFF` | Светлые секции (История, Партнёры, Контакт) |
| `--gold` | `#C9A84C` | Только логотип NUR· и интро |
| `--gold2` | `#E8C97A` | Арабский текст в интро |
| `--teal` | `#00B4A6` | SARDOR AI — единственный акцент, больше нигде |
| `--g1` | `#0D0D0D` | Фон тёмных вторичных секций |
| `--g2` | `#111111` | Разделители, бордеры |
| `--g4` | `#333333` | Плейсхолдеры, копирайт |
| `--g5` | `#555555` | Вторичный текст (тёмный фон) |
| `--g6` | `#888888` | Описания, подписи |

**Правило монохрома:** золото только в логотипе и хадис-цитате. Везде остальном — чёрный/белый/серый. Один акцент, тысяча оттенков серого.

## ✏️ Типографика

| Роль | Шрифт | Вес | Применение |
|---|---|---|---|
| Display/Hero | Barlow Condensed | 900 | Заголовки, числа |
| Body/UI | Space Grotesk | 300–600 | Основной текст, навигация |
| Arabic | Amiri | 400/700 | Хадисы |

- Заголовки `clamp(48px→100px)`, `line-height: 0.88`, `letter-spacing: -0.02em`
- Outline-текст: `-webkit-text-stroke: 2px` для контраста
- Uppercase для display, mixed case для body
- Sec-labels: `10px / 500 / .20em letter-spacing / UPPERCASE`

## 🏗️ Ритм страницы (светлое/тёмное чередование)

Интро/Манифест/Клиенты → тёмное. История → **белое**. Услуги/Портфолио/Статистика → тёмное. Партнёры → **белое**. Стандарты (Шариат) → тёмное. Контакт → **белое**. Footer → тёмное.
Белые секции = "воздух" Apple-типа между тёмными блоками, не более 2 подряд в одном тоне.

## 📐 Spacing (4px база)

```
Container max-width: 1400px / padding 0 56px
Section padding: 100–120px 0
Card padding: 40px 36px
Grid gap: 0–2px (жёсткая Apple-сетка)
Шкала: 4, 8, 16, 24, 32, 40, 56, 80, 120
```

## 🃏 Компоненты (жёсткие правила)

- **Radius везде 0** — острые Apple-углы, без исключений
- Карточки (тёмный фон): border `1px solid #111`, hover `rgba(255,255,255,.015)`
- Карточки (светлый фон): border `1px solid #EBEBEB`, hover `#FAFAFA`
- Кнопки: инвертированные (тёмный фон → белая кнопка с чёрным текстом, и наоборот). **Золотых кнопок нет нигде**, кроме submit формы
- Навигация: `backdrop-filter: blur(20px)`, `background rgba(0,0,0,.96)`
- Анимации: `≤500ms`, `cubic-bezier(0.16, 1, 0.3, 1)`, hover-эффекты едва заметны

## 🚫 Manhaj Filter — блокирующее ограничение, не эстетика

- **ЗАПРЕЩЕНО:** изображения людей/животных с головами, инструментальная музыка, женские образы
- **РАЗРЕШЕНО:** геометрия, каллиграфия, архитектура (Кааба, мечети), природа
- Portfolio/product cards → SVG геометрические паттерны вместо фото людей
- Хадисы — только сахих/хасан, с указанием иснада и учёного (аль-Альбани, ибн Баз, аль-Усеймин, аль-Фаузан)

Если задача требует нарушить это правило (например, просят добавить фото человека на карточку продукта) — сообщи об этом пользователю явно и предложи geometric/calligraphy альтернативу, не нарушай молча и не пропускай проверку.

## 🧠 Когнитивные UX-паттерны (адаптация UX Core, keepsimple.io/ru/uxcore)

Используй для обоснования UI-решений, а не только "на вкус":

| Паттерн | Применение в NUR |
|---|---|
| Von Restorff | Единственный teal-акцент на монохроме (Sardor AI) |
| Hick's Law | Один primary CTA на экран |
| Aesthetic-Usability | Монохром+типографика = сигнал доверия B2G/B2B |
| Cognitive Fluency | Простой шрифт, много воздуха |
| Chunking | Одна идея на секцию |
| Peak-End Rule | Финальный экран (submit) — самый чистый |
| Authority Bias | Хадисы с иснадом и учёным |
| Halo Effect | "Партнёры" сразу после "Истории" |
| Framing Effect | Продукты через пользу, не через страх |
| Zeigarnik Effect | Прогресс-индикаторы в формах |
| Consistency Bias | Один язык дизайна во всех трёх отрядах |

**Этическая рамка (обязательна):** только паттерны, снижающие когнитивную нагрузку и повышающие ясность. Никаких манипулятивных dark patterns — ложный дефицит, fake-таймеры, скрытые условия — это конфликтует с честностью транзакции (амана), обязательной для халяль-брендов.

**Чек-лист перед релизом любого экрана:**
- [ ] Один primary CTA?
- [ ] Нет ложного давления/дефицита?
- [ ] Финальный шаг — самый чистый экран?
- [ ] Акцентный цвет использован не более чем в одном месте?
- [ ] Manhaj Filter соблюдён без исключений?

## 🤖 Sardor AI — единственное цветное исключение
