# 💸 Cheap Generation — дешёвая альтернатива Higgsfield

Задача этого скилла: закрывать те же сценарии, что обычно решают через Higgsfield (AI-видео, AI-изображения, консистентные персонажи, рекламные креативы), но через инструменты, уже включённые в сессию — без отдельной подписки на Higgsfield.

## ⚙️ Почему дешевле

- Higgsfield продаётся как отдельная подписка с кредитами на генерацию (от $9–$249/мес по тарифным планам на момент публикации — проверяй актуальные цены перед точными сравнениями в контенте, не утверждай цифру "в 10 раз" как факт без проверки).
- Artlist MCP (`mcp__artlist__*`) уже подключён к этой среде — генерация изображений, видео и озвучки идёт через него без дополнительной внешней подписки.
- Итог: для большинства задач (обложка, рекламный креатив, короткий видеоролик, AI-баннер) не нужен отдельный инструмент — работа делается прямо в Claude Code.

**Правило для любого маркетингового текста/скрипта, где утверждается конкретное "в 10 раз дешевле":** формулируй как позиционирование/оффер, а не как проверенный факт с цифрой, если точное сравнение тарифов не сделано в моменте.

## 🖼️ Генерация изображений и видео

1. Для любой генерации — сначала `mcp__artlist__get_model_config`, применяй дефолты без вопросов пользователю.
2. Выбирай модель сам, не спрашивай пользователя про модели/настройки, если это не критично.
3. `generate_image` / `generate_video` → сразу `get_generation_status` в цикле до готовности.
4. Для видео: если пользователь не задал длительность — бери дефолт модели, сообщи длительность вместе с результатом.
5. Никогда не называй пользователю ID моделей/групп/voice — только человекочитаемое имя.

## 🕌 Manhaj Filter — обязателен для любой генерации

Перед любым `generate_image` / `generate_video` для FURSAN·FURKAN, TASLIM или NUR Mediaholding — сверься с `.claude/skills/nur-design-standard/SKILL.md`:

- **Запрещено:** лица/головы людей и животных, женские образы, инструментальная музыка в озвучке.
- **Разрешено:** геометрия, каллиграфия, архитектура (Кааба, мечети), природа, продуктовые сцены без лиц.
- Если промпт пользователя нарушает фильтр — сообщи явно и предложи geometric/calligraphy альтернативу в промпте генерации. Не генерируй молча в обход правила.

## 📐 Стиль результата

Если генерация идёт под UI/маркетинг NUR-продуктов — итоговая картинка/видео должны соответствовать `docs/NUR_DESIGN_SYSTEM.md`: монохром, один акцент (`--teal #00B4A6`), Apple-геометрия, без золота вне логотипа/интро.
