# 4. Accessibility — доступность

## Контраст (WCAG 2.2)
- Обычный текст — не ниже 4.5:1. Крупный текст (от 24px, или 18.66px жирный) — 3:1.
- Иконки, границы полей, фокус — 3:1 к фону.
- Проверка NUR-палитры: серый `#555` на `#000` — 2.8:1, для основного текста не годится,
  только для крупного/декоративного. `#888` на `#000` — 5.9:1, годится для подписей.

## Размер цели
- Apple: 44×44pt.
- WCAG 2.2: минимум 24×24 CSS px (AA, 2.5.8), рекомендовано 44×44 (AAA, 2.5.5).
- Берём 44 для всего, что нажимают пальцем.

## Клавиатура
- Всё, что кликается, доступно с Tab, в логичном порядке.
- Видимый фокус: `:focus-visible { outline: 2px solid currentColor; outline-offset: 2px; }`.
  `outline: none` без замены запрещён.
- Ссылка «Перейти к содержимому» первой в документе.
- Модалка держит фокус внутри, Esc закрывает.

## Скринридеры (VoiceOver, TalkBack, NVDA)
- Семантика раньше ARIA: `<button>`, `<nav>`, `<main>`, `<h1>…<h3>` по порядку.
- У иконок-кнопок есть `aria-label`. Декоративные SVG — `aria-hidden="true"`.
- `alt` описывает смысл картинки; для декора `alt=""`.
- Динамические сообщения (ошибка, «добавлено в корзину») — `aria-live="polite"`.
- `lang` у `<html>` и у вставок на другом языке (арабский хадис: `lang="ar" dir="rtl"`).

## Системные настройки пользователя
```css
@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation: none !important; transition: none !important; } }
@media (prefers-color-scheme: dark) { /* тёмные токены */ }
@media (prefers-contrast: more) { /* усилить линии и серые */ }
```
- Размер шрифта в `rem`, чтобы работало увеличение текста браузера (аналог Dynamic Type).
- Масштаб страницы до 200% без горизонтального скролла.
