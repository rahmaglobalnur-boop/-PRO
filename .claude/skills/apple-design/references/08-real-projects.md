# 8. Real Projects — дашборд, CMS, SaaS

## Dashboard
- Сверху 3–5 главных чисел, не 12. Остальное — ниже или по клику.
- Число крупно, подпись мелко, изменение — со знаком и периодом («+12% к прошлой неделе»).
- Цвет только для смысла (рост/падение/тревога). Графики монохромные, акцент — на одной серии.
- Навигация: sidebar на десктопе, tab bar или меню на телефоне.
- Каждый блок имеет пустое, загрузочное и ошибочное состояние.
- Для графиков — скил `dataviz`.
- NUR-вариант: чёрный фон, числа Barlow Condensed 900, подписи sec-label 10px caps.

## CMS / админка
- Список → деталь → редактирование. Как Настройки или Почта на Mac: sidebar, список, контент.
- Главное действие («Опубликовать») одно и всегда в одном месте.
- Автосохранение черновика и видимый статус: «Черновик · сохранено 14:02».
- Разрушительные действия (удалить) — с подтверждением и возможностью отменить.
- Таблицы: липкий заголовок, выравнивание чисел вправо, фильтры над таблицей.

## SaaS (маркетинговый сайт + продукт)
Сайт:
- Hero: что это, для кого, одно действие. Скриншот продукта как главный визуал.
- Дальше — по одной функции на секцию, чередование светлых и тёмных секций.
- Цены: 2–3 тарифа, рекомендуемый выделен размером/обводкой, не кричащим цветом.
- Без ложного дефицита и таймеров (этическая рамка NUR).
Продукт:
- Онбординг: пустое состояние с одним первым шагом вместо тура из 7 подсказок.
- Настройки сгруппированы, как в iOS: группы по 3–7 строк.
