# 2. Components — кнопки, поля, навигация

## Кнопки
Иерархия, а не набор цветов:
| Роль | iOS-стиль | Как на вебе |
|---|---|---|
| Главное действие | Filled (прокрашенная) | Сплошная заливка акцентом / инверсия (в NUR: белая на чёрном) |
| Второстепенное | Tinted / Gray | Полупрозрачная заливка или обводка 1px |
| Третье | Plain (текст) | Текстовая ссылка |
| Разрушительное | Красный текст/заливка | Только с подтверждением |

- Минимальная зона нажатия 44×44pt. Кнопка может выглядеть меньше, но хит-зона — нет.
- Подпись — глагол: «Купить», «Сохранить», а не «ОК» и «Далее» без контекста.
- Одна Filled-кнопка на экран.
- Состояния: default, hover (только на вебе/Mac), pressed, focus, disabled, loading.

## Поля ввода
- Подпись над полем или внутри как label, placeholder не заменяет подпись.
- Правильный тип клавиатуры: `type="email"`, `inputmode="numeric"`, `autocomplete="tel"`.
- Ошибка — под полем, простым текстом, что исправить. Не красить всю форму в красный.
- Валидация при уходе из поля, а не на каждой букве.
- Переключатели (Switch) — для мгновенного эффекта; чекбоксы — для выбора, который подтверждается кнопкой.

## Навигация
| Паттерн | Когда |
|---|---|
| Tab bar (2–5 вкладок) | Разделы одного уровня на телефоне |
| Navigation bar + back | Иерархия: список → деталь |
| Sidebar | Планшет, десктоп, много разделов |
| Toolbar | Действия над текущим экраном |

- Tab bar не используют для действий (кнопка «+» во вкладке — антипаттерн).
- Заголовок экрана говорит, где пользователь. Large Title сворачивается при скролле.
- На вебе аналог: липкий хедер с `backdrop-filter: blur(20px)`, полупрозрачный фон
  (в NUR: `rgba(0,0,0,.96)`, линия `rgba(255,255,255,.07)`).
